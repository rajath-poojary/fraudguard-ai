# Frontend (Next.js)

Analyst UI. Scaffold only: no screens or API calls yet.

## Layout

| Path | Role |
|------|------|
| `src/pages/` | Route-level screens (login, dashboard, live, alerts, cases) |
| `src/components/` | Shared UI (tables, score badges, layout chrome) |
| `src/services/` | HTTP and WebSocket clients |
| `src/hooks/` | Auth, live feed, query helpers |
| `public/` | Static assets |

Pages live under `src/pages` (Next.js Pages Router) to match the approved folder map.
